Koneksi Database (Google Sheets via Apps Script)

Cara memasang database gratis (Google Sheets + Apps Script):
  1. Buat Google Sheet baru bernama Havva Gold DB.
  2. Buka Extensions → Apps Script, hapus isi bawaan, lalu tempel kode Code.gs yang sudah disediakan bersama aplikasi ini.
  3. Jalankan fungsi setupSheets sekali dari toolbar Apps Script (izinkan akses saat diminta).
  4. Klik Deploy → New deployment → Web app. Set Execute as: Me dan Who has access: Anyone.
  5. Salin URL yang berakhiran /exec, tempel di kolom di atas, lalu klik "Simpan & Uji Koneksi".
